# AAVSO public utilities

A collection of small, self-contained utilities maintained by the
[AAVSO](https://www.aavso.org/).

Each project lives in its own directory with its own `pyproject.toml`, tests,
and documentation, and is versioned and released independently.

## Contents

| Path | Description |
| --- | --- |
| [`schemas/starlist`](schemas/starlist) | JSON-schema definition and generators for AAVSO smart-telescope starlists |
