# aavso-starlist-schema

JSON-schema definition and generators for AAVSO smart-telescope starlists.

This package defines the [pydantic](https://docs.pydantic.dev/) models that
describe an AAVSO Smart Telescope starlist (`StarItem`, `StarList`,
`StarListSet`) and provides helpers to emit the schema as JSON or as a
human-readable markdown table.

## Installation

```bash
pip install aavso-starlist-schema
```

## Usage

### From Python

```python
from aavso_starlist_schema import generate_starlist_schema

# Display the schema on the screen
print(generate_starlist_schema())

# Save the schema to a file
with open("starlist_schema.json", "w") as f:
    f.write(generate_starlist_schema())
```

To generate a markdown table describing the schema:

```python
from aavso_starlist_schema import StarList, StarListSet

print(StarListSet.markdown_table())
print(StarList.markdown_table())
```

### From the command line

A console script is installed with the package:

```bash
# Write the JSON schema to <file_name>.json
aavso-starlist-schema <file_name>

# Write a markdown table to <file_name>.md
aavso-starlist-schema --markdown <file_name>
```

## Reference schema files

The reference schema files under
`src/aavso_starlist_schema/data/` are **autogenerated** and should not be
edited by hand. Regenerate them after changing the schema (and after tagging a
release, so the embedded version is correct):

```bash
aavso-starlist-schema src/aavso_starlist_schema/data/schema_definition
aavso-starlist-schema --markdown src/aavso_starlist_schema/data/schema_definition
```

## Development

This project uses [uv](https://docs.astral.sh/uv/) and is versioned from git
tags via `hatch-vcs`.

```bash
uv sync --extra dev   # create the environment and lockfile
uv run pytest         # run the tests
```
